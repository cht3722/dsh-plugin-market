安装前先确认
先准备本地运行环境，再安装插件。下方提供 Windows PowerShell 步骤，其他系统请按安装文档配置。

      
DSH 版本
0.2.1-rc.2；插件版本 0.1.0-alpha.3。
本机依赖
Node.js 24+、Python 3.12+，以及与插件版本匹配的 AgentLineage Core。

      
新改动需要刷新快照＋
插件按需生成快照。继续改文件后，发送“刷新当前会话的分析材料”，再查看新增记录。
部分操作可能没有完整记录＋
未导入的会话、缺少成功回执的调用，以及 shell 脚本内部的文件操作，可能留下记录缺口。
查到来源后，仍需验证结果＋
来源和引用能帮你核对过程；代码是否正确、结论是否成立，仍要结合测试和实际结果判断。

    


    

      
安装并完成第一次查询
按顺序完成下面五步。首次查询使用上面的发布说明例子。

      
本页步骤

  2. 在 DSH 安装插件
  3. 确认服务已经就绪
  4. 运行发布说明例子
  5. 打开视图查看记录
完整安装文档 ↗

        
  1. 01
    准备本地运行环境
    准备 Node.js 24+ 和 Python 3.12+，检出对应发布版本并安装 Core。
    PowerShell · Windows
    git clone --branch dsh-agentlineage-v0.1.0-alpha.3 --depth 1 https://github.com/fuxi-ailabs/AgentLineage.git
cd AgentLineage
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install ./components/core
$env:AGENTLINEAGE_PYTHON = (Resolve-Path .\.venv\Scripts\python.exe).Path
    完成后应看到Core 安装完成，当前终端的 AGENTLINEAGE_PYTHON 指向 .venv 内的 Python。
    从设好环境变量的同一终端启动 DSH，让插件能找到这个 Python。其他平台按安装文档配置等效的 Python 路径。
  2. 02
    在 DSH 安装插件
    打开「插件」→「实验性插件」旁的「更多」，启用「自定义插件市场」。在「发现」→「添加索引源」填入下方地址，安装 AgentLineage 0.1.0-alpha.3。
    插件市场索引
    https://fuxi-ailabs.github.io/dsh-plugin-market/index.json
    完成后应看到AgentLineage 0.1.0-alpha.3 出现在已安装插件中。
    已有同名旧插件时先卸载旧版，再安装新版。
  3. 03
    确认服务已经就绪
    在项目会话中发送下面这句话，检查插件能否连接到 Core。
    发送给 DSH
    请调用 lineage_status，确认 Core 能力包含 dsh-native-v4。不要显示任何 token。
    完成后应看到能力列表包含 dsh-native-v4。首次 binding 为 null 是正常的。
  4. 04
    运行发布说明例子
    复制下面的提问，让 DSH 创建发布说明并修改两次，再查询改动来源。
    发送给 DSH
    请用 DSH 的 write 工具创建 release-note.md，内容为“# 搜索功能发布说明\n功能：新增搜索\n状态：草稿”；再用 edit 分两次修改：先把“新增搜索”改为“支持标题和标签搜索”，再把“草稿”改为“待评审”。不要使用 shell 写文件。完成后刷新当前会话的 Lineage 快照，查询这个文件的三次写入，给出来源会话、调用、成功回执和原文引用。
    完成后应看到release-note.md 有三次确认写入；最后一次将“草稿”改为“待评审”，并有对应的调用和回执引用。
  5. 05
    打开视图查看记录
    让 DSH 打开当前快照的 Viewer，选中文件并展开 diff。后续又改了文件时，刷新快照再查询。
    发送给 DSH
    打开当前分析快照的 Viewer。
    完成后应看到选中 release-note.md 后，能查看三次写入及对应的 diff。
    Viewer 首次打开需要本机登录；按安装文档在本机读取凭据并粘贴到登录框，不要把凭据发给 Agent。Core 重启后需重新登录。
